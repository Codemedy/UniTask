## Сценарий живого демо (≈ 5 минут)

> Перед выступлением: **Settings → Reset demo data**. Даты демо-данных считаются от текущего дня,
> поэтому всегда будут «просроченные», «завтрашние» и «на этой неделе».

1. **Dashboard.** «Утром студент открывает UniTask и сразу видит: 6 дедлайнов на неделе, 2 просрочено, какие пары сегодня, прогресс».
2. Отметить задачу выполненной прямо на дашборде. Счётчики, кольцо прогресса и лента активности обновились мгновенно.
3. **Tasks → New task** (или клавиша **N**): «Lab 6: JavaScript events», курс Web Development, High, дедлайн послезавтра,
   2 подзадачи → *Create*. Показать вкладки *Overdue / This week*, фильтр по курсу и поиск.
4. Попробовать сохранить пустую задачу: появится сообщение *Title is required* (валидация).
5. **Schedule**: клик по пустой ячейке → новая пара. Поставить её на время существующей пары → *Overlaps with…*
6. **Notes**: поиск «grid» с подсветкой, клик по тегу `#exam`, закрепить заметку звёздочкой.
7. **Courses → удалить «Database Systems»**: окно подтверждения показывает каскад
   (*2 classes will also be deleted · 4 tasks will be kept but unlinked*). Это ON DELETE CASCADE / SET NULL.
8. **Settings**: переключить тёмную тему; показать **Database inspector** (сырые JSON-строки в LocalStorage)
   и **Check integrity**; *Export JSON*.
9. Перезагрузить страницу: все изменения на месте, данные сохранены в браузере.
10. Сжать окно или открыть на телефоне: адаптивная вёрстка.

## Возможные вопросы и ответы

**Почему LocalStorage, а не настоящая база данных?**
Так требует ТЗ первой версии: фронтенд-прототип без регистрации и облака. При этом сохранено поведение настоящей
реляционной БД (ключи, FK, каскады, проверки), а `docs/schema.sql` даёт готовую схему PostgreSQL для v2.
Интерфейс общается только со слоем `db.js`, поэтому замена хранилища не затронет страницы.

**Что будет, если очистить кэш браузера?**
Данные удалятся, это ограничение LocalStorage. Поэтому есть *Export / Import JSON*. В v2 появится облачная синхронизация.

**Сколько данных поместится?**
Около 5 МБ на сайт. Демо-семестр занимает примерно 35 КБ, то есть хватит на тысячи задач.

**Почему без React или Vue?**
ТЗ задаёт HTML, CSS и JavaScript. Кроме того, приложению не нужна сборка, у него нет зависимостей,
и каждый участник может прочитать весь код. Архитектура с контрактом `mount / update` и событием `change`
повторяет ту же идею однонаправленного потока данных.

**Как защищены данные от XSS?**
Весь пользовательский текст экранируется функцией `esc()` перед вставкой в HTML, на это есть автотест.

**Как вы проверяли, что всё работает?**
9 модульных тестов слоя данных (`npm test`) и сквозная проверка сценариев в Chromium через Playwright
(включая мобильный режим и тёмную тему).

**Что дальше?**
Неделя 6 по плану: пользовательское тестирование с однокурсниками, анализ опроса (проценты и графики),
исправления. Дальше v2: аккаунты, облако, напоминания о дедлайнах, PWA.
